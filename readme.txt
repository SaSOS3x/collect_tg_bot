Бот в процессе разработки, он время от времени дополняется и развивается, на данный момент есть 3 готовых версии, но основная находится в разработке в ветке develop

Основа данного бота написанна с помощью промта в LLM-модель, целью такого эксперимента считается наблюдением, за способностью современной нейросети построения алгоритмов.
Основной шаблон взят с ии для упрощения и ускорения разработки, далее идет моя личная доработка.

Бот способен отправлять посты от имени пользователя следующих категорий:

1. Текстовые посты
2. Посты с фотографией
3. Посты с видео
4. Посты с файлами
5. Посты с аудиофайлами
6. Посты с голосовым сообщением
7. Посты с медиа-группой

Также бот сохраняет данные о отправленных в канал сообщениях в базу данных sqlite (я знаю, что она не работает асинхронно, логично использовать любую другую бд для таких приложений, например Postgresql)
